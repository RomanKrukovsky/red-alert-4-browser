# RA4 / Global Crisis 2040 — Библия Юнитов и Техники (Unit Roster Bible v3.0)

**Статус документа:** Официальный номенклатурный справочник боевых единиц.  
**Язык:** Русский / English Callsigns  
**Архитектура:** 3-Уровневая система (Base Doctrine Platforms -> National Variants -> Commander T3 Units).  

---

## 0. Общие принципы номенклатуры и логистики

Каждая боевая единица в `packages/sim-core` и `packages/content-runtime` определяется следующей структурой параметров:

```typescript
export interface UnitStats {
  id: string;
  name: string;
  doctrineId: BaseDoctrineId;
  tier: 1 | 2 | 3;
  cost: { credits: number; energy?: number };
  buildTimeSec: number;
  
  // Боевые параметры
  hp: number;
  armorType: 'Unarmored' | 'LightArmor' | 'HeavyArmor' | 'Structure';
  speed: number; // tiles per second
  range: number; // tiles
  dps: number;
  damageType: 'Kinetic' | 'Explosive' | 'Energy' | 'Cyber';
  
  // Логистические контуры
  fuelMax: number;        // Max fuel capacity (0 = does not use fuel)
  fuelBurnRate: number;   // Fuel burned per tile moved
  ammoMax: number;        // Max ammo shots before reload/resupply needed
  c2Required: boolean;    // Requires operational C2 relay connection
  ewSusceptibility: number; // 0.0 (immune) to 1.0 (fully disabled by EW)
}
```

## 1. Eastern Heavy Echelon (Тяжёлая сухопутная архитектура)
*Базовые государства: Россия, Индия.*  
*Ключевая особенность: Максимальная броня, эшелонированная артиллерия, мощные тяжелые ПВО, статичные укрепрайоны.*

### 1.1. Пехота
* **`RU_INF_Rifleman` — Мотострелок МС-12 «Рубеж» (T1)**
  * *Роль*: Основная линейная пехота. Захват зданий, окопание.
  * *Логистика*: Ammo: 100, C2: False, EW: 0.0.
  * *Способность*: `Укрепиться` (+50% брони в укрытии/траншее).
* **`RU_INF_AATeam` — Зенитный расчёт ПЗК-9 «Заслон» (T1)**
  * *Роль*: ПВО пехоты, эффективен против низколетящих БПЛА и вертолётов.
  * *Логистика*: Ammo: 12, C2: False, EW: 0.1.
* **`RU_INF_Engineer` — Инженер-сапёр ИС-3 «Мастер» (T1)**
  * *Роль*: Захват нейтральных узлов, ремонт техники, разминирование/минирование.

### 1.2. Бронетехника
* **`RU_ARM_IFV` — БМП-27 «Курган» (T1)**
  * *Роль*: Легкая броня, перевозка 1 отряда пехоты, 30-мм автоматическая пушка.
  * *Логистика*: Fuel: 150, Ammo: 200, C2: False, EW: 0.2.
* **`RU_ARM_MBT` — Основной танк ОБТ-92 «Гранит-М» (T2)**
  * *Роль*: Тяжелая фронтовая сила. 125-мм гладкоствольное орудие + КАЗ «Арена-М» (сбивает 1 ракето-снаряд раз в 10 сек).
  * *Логистика*: Fuel: 200 (Burn: 2.0/tile), Ammo: 40, C2: False, EW: 0.2.
* **`RU_ARM_Heavy` — Тяжёлый танк прорыва ТТП-11 «Воевода» (T3 — Танковый Командир)**
  * *Роль*: Сверхтяжелый танк с спаренным орудием и усиленным бронированием.
  * *Логистика*: Fuel: 300, Ammo: 60, C2: False, EW: 0.3.

### 1.3. Артиллерия, ПВО и РЭБ
* **`RU_ART_MLRS` — Термобарическая РСЗО ТРС-18 «Зарево» (T2)**
  * *Роль*: Залповый огонь по площади. Зачищает пехоту в зданиях и укрытиях.
  * *Логистика*: Fuel: 120, Ammo: 3 залпа (требует машинный БК), C2: False, EW: 0.4.
* **`RU_SUP_EW` — Комплекс РЭБ «Омут-3» (T2)**
  * *Роль*: Мобильный генератор помех. Подавляет вражеские БПЛА и радарные системы в радиусе 15 клеток.
  * *Логистика*: Fuel: 180, Power: 50, C2: False, EW: 0.0 (Источник РЭБ).

### 1.4. Авиация и Снабжение
* **`RU_AIR_Gunship` — Штурмовой вертолёт ШВ-38 «Коршун» (T2)**
  * *Роль*: Охотник за танками. ПТУР + Нары.
  * *Логистика*: Fuel: 100, Ammo: 16 ПТУР, C2: False, EW: 0.5.
* **`RU_LOG_Supply` — Грузовик снабжения и заправки «Ока-4» (T1)**
  * *Роль*: Автоматическая заправка топливом и пополнение БК техники в радиусе 4 клеток.

## 2. Western Precision Network (Западная Сетецентрическая)
*Базовые государства: США, Великобритания.*  
*Ключевая особенность: Высокточное оружие, авиаудары, БПЛА-пеленгаторы, C2-сеть, высокая стоимость.*

### 2.1. Пехота
* **`US_INF_Rifleman` — Стрелок M6 «Sentinel» (T1)**
  * *Роль*: Высокоточная пехота с коллиматорами и цифровой связью.
  * *Логистика*: Ammo: 120, C2: True (дает +20% к дальности при наличии C2), EW: 0.2.
* **`US_INF_Lancer` — Ракетный расчёт FGM-31 «Lancer» (T1)**
  * *Роль*: Самоотводящиеся противотанковые ракеты Top-Attack.
* **`US_INF_Sniper` — Снайпер R-9 «Longwatch» (T2)**
  * *Роль*: Стелс-ликвидатор пехоты и расчетов артиллерии. Лазерный целеуказатель для авиации.

### 2.2. Бронетехника
* **`US_ARM_Scout` — Разведмашина LAV-41 «Kestrel» (T1)**
  * *Роль*: Скоростная разведка, радарный сканер малого радиуса.
* **`US_ARM_MBT` — Основной танк M14 «Bulwark» (T2)**
  * *Роль*: Технологичный танк с динамической защитой и цифровой системой управления огнем.
  * *Логистика*: Fuel: 180, Ammo: 42, C2: True, EW: 0.4.
* **`US_ARM_Stealth` — Маскировочный танк XM27 «Refraction» (T3 — Стелс Командир)**
  * *Роль*: Генератор видического преломления (невидимость в покое), оптический лазер.

### 2.3. Артиллерия, C2 и Авиация
* **`US_ART_Railgun` — Рельсовая САУ XM190 «Oracle» (T3)**
  * *Роль*: Сверхдальнобойная кинетическая артиллерия с прямолинейным пробитием.
* **`US_SUP_C2` — Мобильный C2-Штаб «Skywatch» (T2)**
  * *Роль*: Излучатель C2-сигнала. Увеличивает дальность стрельбы всех союзных юнитов на 25%.
* **`US_AIR_Reaper` — Ударный БПЛА «Reaper-X» (T2)**
  * *Роль*: Беспилотный патруль. Точечный пуск 2х Hellfire.
  * *Логистика*: Fuel: 150, Ammo: 2, C2: **Required** (При потере C2 или под РЭБ уходит на базу).
* **`US_AIR_Bomber` — Стелс-бомбардировщик B-39 «Nightveil» (T3)**
  * *Роль*: Невидимый для обычных радаров сброс планирующих бомб JDAM.

| Категория Юнита | Топливо (Fuel) | БК (Ammo) | C2 Требование | Уязвимость к РЭБ |
| :--- | :--- | :--- | :--- | :--- |
| **Пехота** | Нет | Качество (перезарядка) | Опционально | 0% |

## 8. Архитектура интеграции с Data Assets (`packages/content-runtime`)

Все юниты описываются в `zod`-схеме `packages/content-schema/src/unit.schema.ts`:

```typescript
import { z } from 'zod';

export const UnitSchema = z.object({
  id: z.string(),
  name: z.string(),
  doctrineId: z.string(),
  tier: z.number().min(1).max(3),
  cost: z.object({
    credits: z.number(),
    energy: z.number().optional(),
  }),
  buildTimeSec: z.number(),
  stats: z.object({
    hp: z.number(),
    armorType: z.enum(['Unarmored', 'LightArmor', 'HeavyArmor', 'Structure']),
    speed: z.number(),
    range: z.number(),
    dps: z.number(),
    damageType: z.enum(['Kinetic', 'Explosive', 'Energy', 'Cyber']),
  }),
  logistics: z.object({
    fuelMax: z.number(),
    fuelBurnRate: z.number(),
    ammoMax: z.number(),
    c2Required: z.boolean(),
    ewSusceptibility: z.number().min(0).max(1),
  }),
});
```
