## Дизайн-токены и Темы

Проведен анализ тонов и форм:
- **СССР**: `#8B0000` (Тёмно-красный), `#2b2b2b` (Графит/металл), острые углы, индустриальный bevel.
- **Альянс**: `#0055ff` (Синий неон), серебристые градиенты, чистая "стеклянная" геометрия.
- **Вост. Коалиция**: `#2E8B57` (Нефрит), `#FFD700` (Золото), орнаментальные скосы.
- **Хронолегион**: `#8A2BE2` (Фиолетовый), неоновое свечение, асимметричные полигоны.
